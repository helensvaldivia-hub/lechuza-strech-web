# lechuza_strech — sitio web

Catálogo web de **lechuza_strech**: kits de mostacilla calibrada, aguja mágica (punch needle) y punto cruz, con lista de pedido por WhatsApp.

Sitio estático (HTML, CSS y JavaScript nativo). Para verlo en tu computador, abre `index.html`.
